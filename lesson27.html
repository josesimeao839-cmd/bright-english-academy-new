📚 Grammar — There is / There are

1️⃣ There is

Use There is with one person or one thing.

There is + singular noun.
There is a bed in the bedroom.
There is a television in the living room.

2️⃣ There are

Use There are with two or more things.

There are + plural noun.
There are two chairs in the kitchen.
There are three windows in the house.

❌ Negative

There isn't + singular noun.
There aren't + plural noun.
There isn't a television in my bedroom.
There aren't any chairs in the bathroom.

❓ Questions

Is there + singular noun?
Are there + plural noun?
Is there a sofa in the living room?
Yes, there is.

Are there two bedrooms?
Yes, there are.

📍 There is / There are + place

There is a table in the kitchen.
There are chairs in the dining room.

💬 Real-life Conversation

Daniel and Sofia are talking about Sofia's new house.

Daniel: Hi, Sofia! How is your new house?
Sofia: It's great! I really like it.
Daniel: How many bedrooms are there?
Sofia: There are three bedrooms.
Daniel: Is there a big living room?
Sofia: Yes, there is. There is a large sofa and a television.
Daniel: What about the kitchen?
Sofia: There is a table, a refrigerator and a stove.
Daniel: Are there any chairs in the kitchen?
Sofia: Yes, there are four chairs.
Daniel: That sounds like a beautiful house!
Sofia: Thank you! You should visit me sometime.

✍️ Writing Challenge

Write 6–8 sentences describing your home.

Try to use:

  • There is...
  • There are...
  • There isn't...
  • There aren't...
  • My favorite room is...

Example:

There are three bedrooms in my house. There is a living room. There is a sofa in the living room. There is a television next to the sofa. There are four chairs in the kitchen. There is a table in the dining room. My favorite room is my bedroom.
