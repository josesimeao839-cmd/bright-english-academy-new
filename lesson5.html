💬 Useful Color Phrases

1️⃣ Asking About a Color

What color is it?
De que cor é?

2️⃣ Answering

It is blue.
É azul.

3️⃣ Favorite Color

My favorite color is green.
A minha cor favorita é verde.

4️⃣ Asking About a Favorite Color

What is your favorite color?
Qual é a tua cor favorita?

📚 Grammar — What Color Is It?

1️⃣ It is + Color

Use It is to describe the color of one object.

It is red.
É vermelho.

It is black.
É preto.

2️⃣ This is + Color

This is a blue bag.
Esta é uma bolsa azul.

This is a green book.
Este é um livro verde.

3️⃣ Color + Noun

In English, the color normally comes before the noun.

A red car.
Um carro vermelho.

A yellow shirt.
Uma camisa amarela.

A black phone.
Um telefone preto.

💬 Real-life Conversation

José and Maria are talking about colors.

José: Hi, Maria! What color is your bag?

Maria: It is blue.

José: Nice! Blue is a beautiful color.

Maria: Thank you! What is your favorite color?

José: My favorite color is green.

Maria: Green? That's nice!

José: Yes. What color is your phone?

Maria: My phone is black.

José: Is your notebook red?

Maria: No, it isn't. It is yellow.

José: I like yellow too.

Maria: Great! We both like bright colors.
